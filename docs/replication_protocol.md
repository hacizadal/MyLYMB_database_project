# Replication experiment (not yet executed)
Use a disposable MariaDB 11.4.13 primary and replica with unique server IDs, row binlogging and an independently provisioned replication account. Seed identical data and verify replication is caught up before each run. Compare INSTANT, online COPY and blocking COPY under the same workload. Record primary write latency and replica heartbeat age every 100 ms, along with replica SQL thread state and errors. Repeat five times and report maximum lag and time to recover. Do not treat primary availability as proof of replica freshness. No replication results are claimed in this repository.
